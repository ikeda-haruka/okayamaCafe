# CAFE HAREKA（晴果）WordPress テーマ導入・運用マニュアル

岡山県・地産地消カフェ「CAFE HAREKA（晴果）」の公式WordPressテーマです。  
通常のWordPressテーマ（クラシック / ブロックエディタ対応）としても、Reactフロントエンドと連携するヘッドレスCMSバックエンドとしても稼働できる**ハイブリッドCMS設計**となっています。

---

## 1. テーマの特長

- 🍑 **地産地消のブランディングデザイン**:
  岡山の白桃・シャインマスカット・ピオーネ・足守メロンの魅力を最大限に引き出す高級感と温もりある配色。
- 🛡️ **ポートフォリオ実績用注意喚起バナー固定**:
  すべてのページ上部に「ポートフォリオ実績用の架空サイト」である旨の告知バナーが常時固定表示されます。
- 📅 **満席誤予約防止・リアルタイム空き枠予約システム**:
  水曜定休日の自動ロック、時間帯ごとの空き状況（◎余裕あり / △残り1組 / ✕満席クリック不可）、24時間以内の本確定案内を前提とした「仮予約制」ワークフローを標準搭載。
- 🔌 **REST API & ヘッドレスCMS完全対応**:
  カスタム投稿（カフェメニュー、旬果図鑑、お知らせ）のメタフィールドがすべてREST APIに自動公開され、React SPAからもそのまま利用可能。
- 📱 **レスポンシブ・スマートフォン完全最適化**:
  モバイルドロワーナビゲーション、下部固定アクションバー（席予約・アクセス・電話）を完備。

## 3. インストール手順

### ステップ 1: テーマフォルダの配置
WordPress環境のテーマディレクトリに `hareka-theme` をコピーします。

```bash
# WordPressのルートディレクトリにて
cp -r C:/gitHub/okayamaCafe/wordpress-theme/hareka-theme wp-content/themes/
```

### ステップ 2: テーマの有効化
1. WordPress管理画面にログインします。
2. **「外観」 > 「テーマ」** をクリックします。
3. **「CAFE HAREKA - 岡山地産地消カフェ」** を選択し、**「有効化」** をクリックします。

### ステップ 3: 推奨固定ページの作成
管理画面の **「固定ページ」 > 「新規追加」** より、以下の5つの固定ページを作成してください。

| ページタイトル | スラッグ (URL) | テンプレート指定 |
| :--- | :--- | :--- |
| **お店について** | `about` | `お店について (About Story)` |
| **カフェメニュー** | `menu` | `カフェメニュー (Menu)` |
| **岡山の果物について** | `fruits` | `岡山の果物について (Fruits Story)` |
| **アクセス・店舗情報** | `access` | `アクセス・店舗情報 (Access & Info)` |
| **ご予約・お問い合わせ** | `contact` | `ご予約・お問い合わせ (Contact & Reservation)` |

> **ヒント**: 固定ページの編集画面右側の「ページ属性」または「テンプレート」欄から、上記の各テンプレートを選択して保存してください。

### ステップ 4: フロントページ（トップページ）の設定
1. 管理画面の **「設定」 > 「表示設定」** を開きます。
2. 「ホームページの表示」を **「固定ページ」** に切り替えます。
3. ホームページに作成したトップ用固定ページ（または空の固定ページ）を指定します。（`front-page.php` が自動適用されます）
4. 投稿ページにお知らせ用のページ（例：`news`）を指定します。
5. 「変更を保存」をクリックします。

### ステップ 5: パーマリンク設定の更新
1. 管理画面の **「設定」 > 「パーマリンク」** を開きます。
2. 「投稿名」(`/%postname%/`) を選択し、「変更を保存」をクリックします。（カスタム投稿タイプのルーティングを正しく反映させるため）

## 4. 管理画面でのコンテンツ更新手順

### 1. カフェメニューの追加・編集
左側サイドメニューの **「カフェメニュー」 > 「新規メニュー追加」** より登録できます。

- **タイトル**: 商品名（例：`岡山県産 清水白桃の極上パフェ`）
- **本文**: 商品の詳しい説明・こだわり
- **アイキャッチ画像**: 商品写真（正方形〜4:3推奨）
- **メニューカテゴリ**:
  - `sweets`（パフェ・タルト・スイーツ）
  - `lunch`（ランチ・食事）
  - `drinks`（果実スカッシュ・コーヒー）
  - `takeout`（バターサンド・コンフィチュール）
- **メニュー詳細情報（カスタムメタボックス）**:
  - 税込価格（例：`1,980円`）
  - 契約農家・産地（例：`赤磐市 吉井果樹園`）
  - 糖度目安（例：`糖度 13〜15度`）
  - 季節限定メニュー（チェックボックス）
  - テイクアウト可能（チェックボックス）
  - おすすめ商品としてトップに掲載（チェックボックス）

### 2. 岡山の果物図鑑の追加・編集
左側サイドメニューの **「岡山の果物」 > 「新規果物を追加」** より登録できます。

- **タイトル**: 品種名（例：`晴王（シャインマスカット）`）
- **英語表記**: （例：`SHINE MUSCAT HAREOU`）
- **旬の時期**: （例：`7月上旬 〜 10月下旬`）
- **糖度**: （例：`糖度 18〜20度以上`）
- **提携農家**: （例：`倉敷市船穂町 / 井原市 ぶどう部会`）
- **美味しさの特徴**: 1行に1つずつ入力（例：`皮ごとサクッと食べられる種なし`）

## 5. ヘッドレスCMS運用の手順（Reactフロントエンドとの連携）

フロントエンドを現在のReact SPA（Vite）としてホストし、WordPressをデータ管理バックエンドとして使う場合の設定です。

1. プロジェクトのルートディレクトリ `C:\gitHub\okayamaCafe` に `.env` ファイルを作成します（`.env.example` をコピー）。
   ```env
   VITE_WP_API_URL=https://your-wordpress-domain.com
   ```
2. Reactアプリは、WordPressの REST API（`/wp-json/wp/v2/posts`、`/wp-json/wp/v2/menu_items`）から自動的にお知らせやメニューデータを取得して動的に反映します。
3. もしWordPressサーバーがメンテナンス中やオフラインの場合でも、自動的にローカルのデータ（`newsData.ts`、`menuData.ts`）にフォールバックするため、サイトが落ちる心配はありません。
