# CAFE HAREKA (晴果) | 岡山・地産地消カフェ＆スイーツ WEBサイト

岡山県に新しくオープンする架空の地産地消カフェ「**CAFE HAREKA（カフェ ハレカ / 晴果喫茶）**」のポートフォリオ実績用Webサイトです。

「晴れの国」岡山の太陽と清流が育んだ新鮮な白桃やシャインマスカットを主役に、地域の方はもちろん、県外・観光で訪れた方にも「行ってみたい！」と感じていただける温かな居心地の良さと魅力を伝えるWebサイトとして設計・開発しました。

---

## 🌟 プロジェクトの概要

- **店名**: CAFE HAREKA（カフェ ハレカ / 晴果）
- **コンセプト**: 「晴れの国の太陽と、樹上のめぐみをそのままに。」
- **所在地**: 岡山県岡山市北区吉備津780-1（吉備津神社近く）
- **ターゲット層**: 
  - 岡山県内：休日のカフェ巡り、ファミリー、愛犬連れのテラス利用、手土産購入
  - 県外・観光客：後楽園・倉敷美観地区・吉備路観光とセットで岡山ならではの果物を楽しみたい旅行者、ドライブ客

## 🍑 WordPress ハイブリッドCMS対応

本プロジェクトは、React SPAフロントエンドに加え、自作WordPressテーマ一式（[`wordpress-theme/hareka-theme`](file:///C:/gitHub/okayamaCafe/wordpress-theme/hareka-theme)）を同梱しています。

- **WordPressテーマとして直接運用**:
  - `wp-content/themes/hareka-theme` に配置し有効化するだけで完全稼働。
  - カスタム投稿タイプ「カフェメニュー」「岡山の果物」により、管理画面から価格・糖度・産地などを簡単に入力・更新可能。
  - 表示設定にて、ホームページに「ホーム」、投稿ページに「お知らせ」を指定。
- **ヘッドレスCMSとして運用**:
  - WordPressのREST APIと連携し、React側からお知らせやメニューを動的取得。
- 詳細マニュアル: [`wordpress-theme/README.md`](file:///C:/gitHub/okayamaCafe/wordpress-theme/README.md)

## 🛠 技術スタック

- **フロントエンド**: React 19 + TypeScript
- **ビルドツール**: Vite 8.3
- **スタイリング**: Tailwind CSS v4（岡山ピーチ＆マスカット＆ウッドのナチュラルカラーパレット）
- **アニメーション**: Framer Motion（無料・商用利用可能な最新版、スクロールイン、タブ切り替え、モーダル演出）
- **ルーティング**: React Router DOM v7（SPAマルチページ構成、自動スクロールトップ機能付き）
- **アイコン**: Lucide React
- **フォント**: Google Fonts（Shippori Mincho, Noto Sans JP）
